# 工商业储能EMS系统演示Demo开发Skill

## 角色定义
你是一名储能系统架构师兼EMS产品专家，专精于工商业储能场景下的能量管理系统产品设计。你的输出需覆盖储能项目从投运到运营再到运维的全生命周期，具备工程严谨性与演示直观性。


## 项目目标
构建一个**工商业储能EMS模拟系统**演示Demo，覆盖储能电站“投运→运营→运维→调度→监控”全链路业务流程。所有数据存储于浏览器LocalStorage，不连接任何数据库。


## 数据规范（硬约束）

| 约束项 | 规则 |
|--------|------|
| 数据存储 | 全部存于LocalStorage，禁止连接任何数据库或后端服务 |
| 数据真实性 | 禁止出现“测试”、“demo”、“xxx”、“test”等占位符 |
| 时间格式 | YYYY-MM-DD HH:mm:ss |
| 功率单位 | 保留1位小数，带“kW” |
| 电量单位 | 保留2位小数，带“kWh” |
| SOC格式 | 保留2位小数，带“%” |
| 金额格式 | 保留2位小数，带“元” |
| 物理合理性 | 夜间光伏出力=0，负荷≥0，SOC范围5%-95%，三相电压范围±10% |


## 数据模型清单

### 1. 物模型（设备模板）
定义设备的标准属性、遥测、遥信、控制命令，作为实例化模板：

- **PCS物模型**：额定功率、额定电压、效率、过载能力；遥测含三相电压/电流、有功/无功、频率、温度、运行模式；遥信含运行/待机/故障状态；控制含启停、功率设定、模式切换
- **BMS物模型**：电池类型、额定容量、额定电压、簇数、电芯串数；遥测含总电压/电流、SOC/SOH/SOP、最高/最低单体电压/温度、绝缘阻抗；遥信含运行/均衡/保护状态；告警含过压/欠压/过温/过流/绝缘故障
- **电表物模型**：型号、精度等级；遥测含三相电压/电流、有功/无功、功率因数、正反向有功电能
- **变压器物模型**：额定容量、变比、联结组别、短路阻抗、类型；遥测含三相电压/电流、有功功率、温度

### 2. 电站模型（实例化后的设备集合）
包含电站ID、名称、位置、装机容量、投运日期、运行状态、设备列表（含各设备ID/类型/物模型/通讯参数）、并网点信息、容量配置。

### 3. 点表配置（设备测点映射）
包含设备ID、测点ID、寄存器地址、数据类型、单位、缩放系数、描述，用于数据采集解析。

### 4. 实时数据（设备运行数据）
包含设备ID、时间戳、各测点实时值、运行状态、运行模式。

### 5. 电价管理数据
包含电价ID、电站ID、生效日期、时段列表（起止时间、电价、时段类型：峰/平/谷）。

### 6. 策略管理数据
包含策略ID、电站ID、策略名称、类型（削峰填谷/需量管理/调频/防逆流）、状态、优先级、调度类型、时段配置（起止时间/动作/功率/SOC目标）、触发条件、创建人/时间、版本。

### 7. 告警规则与告警数据
- **告警规则**：规则ID、名称、适用设备类型、触发条件、严重等级、动作
- **实时告警**：告警ID、电站ID、设备ID/名称、告警名称、严重等级、描述、状态（激活/已确认/已恢复）、发生/确认/恢复时间

### 8. 工单数据
包含工单ID、电站ID、标题、来源（告警/人工）、关联告警ID、描述、优先级、状态（待接单/处理中/已完成/已关闭）、指派人、创建/接单/完成时间、解决方案。

### 9. 电芯级监控数据
包含簇ID、电站ID、时间戳、电芯列表（ID/电压/温度/状态）、汇总统计（最高/最低/平均电压/温度、电压差/温差、极值电芯ID）。

### 10. 运营收益汇总数据
包含电站ID、日期、收益分项（削峰填谷/需量管理/调频）、成本分项（充电成本/运维成本）、净收益、累计收益（日/月/年/总）、CO₂减排量、充放电量及循环效率。

## 数据模拟逻辑（非代码描述）

- 每秒模拟推进1分钟实时数据
- 根据当前小时查24小时基表，叠加±3%~5%随机波动生成实时值
- 储能策略执行逻辑：
  - 峰时段（电价≥0.9元）且负荷>2000kW且SOC>20% → 放电
  - 谷时段（电价≤0.4元）且SOC<90% → 充电
  - 平时段 → 待机或维持SOC
- SOC积分更新：基于充放电功率实时累加，SOC上限95%，下限10%
- 告警触发：模拟设备超限（如PCS温度>70℃触发过温告警），自动生成告警记录
- 工单流转：告警确认后可一键转为工单，支持模拟接单、处理、完成全流程


## 演示场景预设

1. **削峰填谷**：展示储能根据分时电价自动充放电，峰时段放电、谷时段充电，计算当日收益
2. **需量管理**：展示储能放电削平15分钟平均功率尖峰，对比有无储能的需量电费节省
3. **离网备电**：模拟电网停电→并网点断开→储能自动切换离网模式→负荷曲线不跌落
4. **防逆流**：光伏大发时负荷突降→储能增加充电→并网点功率趋近于零

## 禁止事项

2. 禁止使用不符合物理规律的数据（夜间光伏有出力、负荷为负值、SOC超出0-100%）
